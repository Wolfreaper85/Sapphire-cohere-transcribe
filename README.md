# Sapphire-cohere-transcribe
Local speech-to-text plugin for Sapphire using Cohere's 2B-parameter Transcribe model. 14 languages, long-form audio, WAV/MP3/M4A/FLAC support. Transcribe via chat, API, or drag-and-drop UI. Lazy-loads on first use, auto-unloads when idle. Fully local, no cloud API. Apache 2.0.
